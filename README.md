# AgentCompany

An experiment in agentic business: an organized company of agents collaborating toward one goal, earning a profit.

The first effort is research and planning: the company's organizational structure, and self-improving loops for seeking profit.
Its research, critique, Daniel's decisions and next-phase tickets are in [`docs/research/2026-11-02-org-and-profit-loops/`](docs/research/2026-11-02-org-and-profit-loops/report.md).
